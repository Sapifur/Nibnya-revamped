# Nibnya-revamped
Pretty good repository for a better nibnya.
# What I did
New features have been added and features such as shizuku for root access, which were unnecessary for my use case of editing world downloads, have been removed. The app supports Android 7 and above, as verified by me on a 2017 tablet, unlike the original nibnya, which didn't support due to the utterly unnecessary shizuku implementation, the app has fixed many bugs that the original nibnya had such as hardcoded write path, and hopefully didn't add any of it's own, it also offers a fallback SAF path selection option. the selected paths will persist even after you close the app, unlike the original.

## Disclosure
The original nibnya was claimed to be built using DeepSeek v4, I have built this version using Claude, so please don't burn me for that.
